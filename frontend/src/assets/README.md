# Ресурсы и изображения

Папка для будущих графических ресурсов проекта (графика конверта,
фоны, иконки, спрайты эффектов).

Соглашения:
- изображения — в `images/`, иконки — в `icons/`;
- SVG предпочтительнее растровых форматов;
- имена файлов — kebab-case (`envelope-flap.svg`).

Пока папка пуста: на текущем этапе используются только CSS-формы.
